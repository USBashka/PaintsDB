# PaintsDB

Десктопное приложение для учёта рецептов красок: компоненты, месячные цены, записи изготовлений, расчёт стоимости, сравнение на 1 кг, Excel и MCP.

## Запуск EXE

Скачайте [готовый выпуск](https://github.com/USBashka/PaintsDB/releases/latest), распакуйте ZIP и откройте `PaintsDB.exe`. После сборки из исходников файл находится в `dist/PaintsDB.exe`. Python и WebView2 устанавливать не требуется: Python, Qt и браузерный движок включены в EXE. Первый запуск распаковывает их во временную папку. База хранится отдельно от EXE.

Для знакомства выберите **Файл → Открыть базу** и `demo/Демонстрация.paintsdb`. Это синтетические данные: три компонента, три рецепта, цены за июль, сентябрь и октябрь 2026 года. Август использует июльский прайс. Для собственных данных выберите **Файл → Создать базу**.

## Работа

- **Компоненты:** код, название, алиасы; для месяца — цена упаковки, объём в литрах и масса литра в граммах. Цена грамма вычисляется автоматически. Можно сохранить компонент без прайса.
- **Рецепты:** выберите компоненты через поиск и задайте массы. Допустимо `20+15+кап`; `кап` равна 1 г. Все описательные поля необязательны, дата по умолчанию текущая. Для сохранения необходимы корректный состав и полный прайс на дату изготовления.
- **Стоимость:** исходный снимок фиксируется при сохранении. Правка прайса снимок не меняет; исправление состава или даты пересоздаёт его.
- **Сравнение:** отметьте варианты одного цвета и нажмите «Сравнить». Составы приводятся к 1000 г и одному месяцу. Нет цены — разрыв графика и перечень недостающих компонентов.
- **Импорт Excel:** выберите файл, проверьте месяц, ошибки, предупреждения и флажки строк. При повторе кода оставьте одну обоснованно выбранную строку. «Импортировать выбранные» применяет отмеченный набор одной транзакцией. Неполный прайс создаёт только компонент; цены нулями не заменяются. Исправляйте ошибки в исходном Excel и повторяйте проверку.
- **Экспорт Excel:** компоненты и использованные ценовые параметры. Сохраняется фактический месяц цены, включая перенесённый прайс. Алиасы и рецепты не входят в обмен и не удаляются при повторном импорте.
- **Резервирование:** **Файл → Резервная копия** создаёт согласованный файл SQLite. Для восстановления откройте копию. Существующие файлы при создании базы, копии и экспорте не перезаписываются.

Настройки и журнал ошибок: `%LOCALAPPDATA%/PaintsDB/`. Последняя база открывается после перезапуска. Работают поиск, фильтры и сортировки в обоих направлениях. Уведомления MCP хранятся только во время работы приложения.

## Исходный код и сборка

Python 3.12 x64, Windows 10/11 x64:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe -m pytest -q --basetemp=.test-local
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
.venv\Scripts\python.exe scripts\package.py
```

Полный набор зависимостей закреплён в `requirements-lock.txt`. Создать новую синтетическую базу: `.venv\Scripts\python.exe scripts\create_demo.py demo\Новая-демонстрация.paintsdb`.

Проверка настоящего Qt-интерфейса со скриншотами: `.venv\Scripts\python.exe scripts\gui_check.py`. Проверка EXE: `PaintsDB.exe --database <база> --data-dir <папка-проверки> --smoke <результат.json>`.

Инвентаризационные XLSX и рабочие базы исключены из Git; разрешена только синтетическая демонстрационная база. Документы практики и сведения предприятия в репозиторий не включены.
