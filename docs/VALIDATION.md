# Проверки PaintsDB 1.0.0

Выполнены 12 октября 2026 года на Windows 11 x64 (10.0.26200), Python 3.12.14, Qt/PySide6 6.8.3. Целевая платформа — Windows 10 x64 1809 и новее; отдельное испытание на чистой Windows 10 ещё не проводилось.

## Автоматические проверки

**44 проверки pytest пройдены**, ошибок и пропусков нет. Покрыты:

- разрешённая арифметика масс, `кап = 1 г`, запрет исполнения кода, нечисловых и неположительных масс;
- контрольный расчёт 1500 → 1650 → 1710 руб., снимок при сохранении, история и сравнение на 1 кг;
- пустые описательные поля, сохранение выражений и восстановление из файла;
- алиасы, неоднозначность поиска, независимые записи одного цвета, удаление используемых компонентов;
- отсутствующая цена, нулевая цена, запрет будущего прайса, атомарность сохранения;
- Excel: повторный импорт, дубли, ошибки, ведущие нули в кодах, точность экспорта, текстовые значения вместо формул;
- резервная копия и восстановление, отказ открытия неверного файла, смена контекста базы и конфликт редакций;
- настоящий HTTP MCP: авторизация, список инструментов, создание/изменение/удаление, общий прикладной слой и защита от устаревшего контекста.

```powershell
.venv\Scripts\python.exe -X utf8 -m pytest -q --basetemp=.test-local
```

## Интерфейс

**12 проверок в настоящем окне Qt WebEngine пройдены**, ошибок JavaScript нет. Скрипт загружает синтетическую базу, выбирает компоненты, вводит выражение, сохраняет рецепт с пустыми реквизитами, строит график и сравнение, проверяет предпросмотр импорта, уведомление MCP и сохранность несохранённых правок при конфликте.

```powershell
.venv\Scripts\python.exe -X utf8 scripts\gui_check.py --height 1080
```

Результат и снимки окна записываются в `.qa/gui-<время>/`. Выбор файла в этом сценарии подменён фиксированным путём тестовой книги; действия в системном файловом диалоге не входят в автоматическую проверку.

## Самостоятельный EXE

`PaintsDB.exe` скопирован в отдельную папку с кириллицей и пробелом, содержащую только EXE и демонстрационную базу. Запуск с отдельной папкой настроек загрузил три рецепта, не сообщил ошибок и штатно завершил процесс. Снимок настоящего окна просмотрен. В EXE включены Python, Qt и Qt WebEngine; обращение к исходному каталогу приложения для запуска не требуется.

```powershell
.\PaintsDB.exe --database .\demo\Демонстрация.paintsdb --data-dir .\проверка --smoke .\результат.json
```
