# Устройство PaintsDB

Приложение рассчитано на одно локальное рабочее место Windows x64. Python 3.12 выполняет расчёты и операции SQLite; pywebview 6.2.1 использует Qt WebEngine 6.8.3 через PySide6. HTML, CSS и JavaScript загружаются локально, внешние CDN отсутствуют. Интерфейс оформлен в стилистике Windows 10: Segoe UI, прямоугольные элементы, системное окно и файловые диалоги.

`domain.py` проверяет числа, месяцы и арифметические выражения через ограниченный обход AST. Функции, атрибуты, степень и произвольный Python не исполняются. Вычисления используют Float; три знака применяются только при показе.

`service.py` — единая точка выполнения операций интерфейса и MCP. RLock упорядочивает обращения из потоков; транзакции атомарно сохраняют рецепт, строки и снимок либо весь выбранный набор импорта. WAL обеспечивает согласованное чтение, резервирование использует SQLite Backup API. Для редактирования проверяется revision. При смене файла меняется context.

`excel.py` поддерживает инвентаризационный формат и собственный экспорт. Месяц определяется из заголовка, листа, имени файла или явного переопределения. Производные значения проверяются по исходным параметрам. Формулы читаются с кешированными результатами; формулы Excel не исполняются. Неполный прайс не становится нулевой ценой. При повторе кода требуется выбрать единственную строку. Проверенный набор применяется одной транзакцией.

`mcp_server.py` публикует тот же Service через официальный SDK MCP. Сервер локальный, требует случайный Bearer-токен. `events` — очередь последних 200 изменений в памяти, не постоянный аудит и не журнал редакций.

## Данные и ограничения

Схема: `schema.sql`, версия 1. Таблицы metadata, components, aliases, prices, recipes, recipe_lines. Уникальны код компонента и пара компонент—месяц. Код цвета не уникален. Алиасы разных компонентов могут совпадать. Используемый компонент удалить нельзя; удаление рецепта каскадно удаляет только его строки.

Снимок хранится в snapshot_total, snapshot_mass и snapshot_price, snapshot_period строк. Правка прайса его не меняет. Изменение состава, исходного выражения или даты пересоздаёт снимок; правка прочих реквизитов сохраняет его. Старые редакции не хранятся. Графики не являются журналом реальных изготовлений.

Это первый выпуск, миграций между опубликованными схемами нет. Файлы с иной user_version отклоняются без изменения. Перед будущей миграцией необходима резервная копия, транзакционное преобразование и проверка восстановления.

Нет склада, прибыли, аккаунтов, облачной синхронизации, распознавания фотографий внутри приложения и интеграции с весами. База не зашифрована. Общий сетевой файл и одновременная запись из нескольких экземпляров не поддерживаются. Права на файл обеспечивает Windows.

Первый запуск onefile EXE распаковывает движок во временный каталог. Целевая платформа — Windows 10 x64 версии 1809 и новее; фактическая проверка выполнена на Windows 11 x64. EXE не подписан. Qt компонуется динамически; лицензии приведены в THIRD_PARTY_NOTICES.md.
